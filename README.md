# Cry-of-Fear-VF

## Présentation

**Cry-of-Fear-VF** est un projet communautaire ayant pour objectif de proposer une **version française doublée vocalement** de *Cry of Fear*.

Le projet comprend notamment :

* La traduction des dialogues et textes.
* Le doublage vocal français.
* Le montage et le traitement des voix.
* L'intégration des voix dans le jeu.
* La création et la distribution d'un mod compatible avec la version Steam du jeu.
